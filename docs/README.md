# Moving-the-cursor - Автоматическое перемещение курсора ![C#](https://img.shields.io/badge/C%23-9.0-purple?style=flat-square)![Platform](https://img.shields.io/badge/Windows-10%2F11-blue?style=flat-square)

Программа для автоматического перемещения курсора мыши по различным траекториям. Полезно для предотвращения блокировки экрана.

## 🚀 Возможности
* 9 различных режимов движения:

	* ⚫ Circle - движение по кругу

	* 🖥 LockScreen - движение с отскакиванием от границ экрана

	* ♾️ Infinity - движение по траектории знака бесконечности

	* 🐌 Spiral - движение по спирали

	* 🔺 Triangle - движение по треугольнику

	* ⬛ Quadrilateral - движение по четырёхугольнику

	* 🛑 Polygon - движение по многоугольнику

	* 〽 RandomPoint - движение к случайной точке

	* 🎲 Random - случайный режим из вышеперечисленных

* Гибкая настройка через конфигурационный файл

* Выход из программы при перемещении курсора пользователем

<br>

## 📦 Скачивание и запуск
1. Скачайте последнюю версию из [Releases](https://github.com/Nelliel2/Moving-the-cursor/releases/)

2. Распакуйте архив в любую папку

3. Настройте параметры в файле MovingCursor.exe.config. По умолчанию установлен случайный режим перемещения

4. Запустите MovingCursor.exe

> ⚠️ Примечание: Некоторые антивирусы могут блокировать программу. Добавьте её в исключения при необходимости.  

<br>
 
## 🖥️ Использование
1. Запустите программу - курсор начнёт движение автоматически

2. Для остановки - переместите курсор

3. Для изменения настроек - отредактируйте конфиг и перезапустите программу  

<br>

## ⚙️ Настройка

Отредактируйте файл MovingCursor.exe.config для настройки программы:

### Выбор режима работы
```
<appSettings>
    <add key="mode" value="Triangle"/>
</appSettings>
```
Доступные режимы: `Random`, `Circle`, `LockScreen`, `Infinity`, `Spiral`, `Triangle`, `Quadrilateral`, `Polygon`, `RandomPoint`

<br>

### Настройка режимов
**⚫ Circle (Круг)**
```
<CircleMode intervalMs="25" step="5" radius="30"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения (количество пикселей)
* `radius` - радиус круга

<br>

**🖥 LockScreen (Экран блокировки)**
```
<LockScreenMode intervalMs="25"/>
```
* `intervalMs` - интервал между движениями (мс)

<br>

**♾️ Infinity (Знак бесконечности)**
```
<InfinityMode intervalMs="25" step="5" radius="20"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения (количество пикселей)
* `radius` - радиус круга

<br>

**🐌 Spiral (Спираль)**
```
<SpiralMode intervalMs="25" stepRadius="3" startRadius="0" loopCount="10" isLoop="true" isReverse="false"/>
```
* `intervalMs` - интервал между движениями (мс)
* `stepRadius` - шаг увеличения радиуса за каждый виток
* `startRadius` - начальный радиус спирали
* `loopCount` - количество витков спирали
* `isLoop` - зацикленность (true - движение в одну сторону, false - движение "туда и обратно")
* `isReverse` - обратное направление (true - к центру, false - от центра)

<br>

**🔺 Triangle (Треугольник)**
```
<TriangleMode intervalMs="25" step="5" point1="100, 100" point2="300, 100" point3="500, 500"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения между вершинами (количество пикселей)
* `point1` - первая вершина треугольника в формате "X, Y"
* `point2` - вторая вершина треугольника в формате "X, Y"  
* `point3` - третья вершина треугольника в формате "X, Y"

<br>

**⬛ Quadrilateral (Четырёхугольник)**
```
<QuadrilateralMode intervalMs="25" step="5" point1="100, 100" point2="300, 100" point3="500, 500" point4="100, 500"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения между вершинами (количество пикселей)
* `point1` - первая вершина в формате "X, Y"
* `point2` - вторая вершина в формате "X, Y"  
* `point3` - третья вершина в формате "X, Y"
* `point4` - четвертая вершина в формате "X, Y"

<br>

**🛑 Polygon (Многоугольник)**
```
<PolygonMode intervalMs="25" step="5" angleCount="6" radius="50"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения между вершинами (количество пикселей)
* `angleCount` - количество углов многоугольника (минимум: 3)
* `radius` - радиус описанной окружности в пикселях

<br>

**〽 RandomPoint (Случайная точка)**
```
<RandomPointMode intervalMs="25" step="5"/>
```
* `intervalMs` - интервал между движениями (мс)
* `step` - шаг движения (количество пикселей)

<br>

## ⚠️ Важные примечания
* Координаты точек должны быть в пределах вашего экрана

* Меньшие значения intervalMs делают движение более плавным, но увеличивают нагрузку на CPU

* Для больших значений radius убедитесь, что фигура помещается на экране

* Программа требует права администратора для управления курсором
